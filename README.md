# Weather Forecast (CSS)

Невеликий статичний проєкт для демонстрації прогнозу погоди з використанням CSS, Tailwind та іконок `weather-icons`.

**Опис:**
- Простий макет сторінки з декількома картками для міст і прикладами погодних іконок.

**Файли:**
- [index.html](index.html) — головна сторінка проєкту.

**Вимоги:**
- Будь-який сучасний браузер (Chrome, Edge, Firefox).

**Запуск локально:**
1. Відкрийте файл [index.html](index.html) у браузері двічі-кліком або через контекстне меню -> "Open with".
2. Або запустіть простий HTTP-сервер у терміналі (рекомендовано для локальних шрифтів/файлів):

```
# Python 3
python -m http.server 8000

# потім відкрийте http://localhost:8000
```
